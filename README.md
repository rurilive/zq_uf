# jobpriority

现状：单队列先进先出。

问题：大租户独占，高优排不到，抢占丢进度。

目标：配额加优先级，保底，抢占续跑和统计。

```bash
python3 demo.py
python3 -m unittest discover -s tests
```

## 配额口径

- 配额按租户 + 滑动时间窗计：窗口内出队次数不超过 `quotas[tenant]`，超限该租户任务跳过。
- 窗口随出队/回收惰性滑动；`reclaim(tenant)` 幂等回收过期用量并记录事件。
- `release(job_id)` 幂等释放执行位，重复调用返回 False 且不重复留档。
- 默认配置（无配额/保底、容量不限）退化为纯 FIFO。

## 抢占口径

- 出队顺序：先补保底档（`guarantees[priority]`，低优优先补），再按优先级高→低、同优先级按等待时间长→短。
- 执行位满时，更高优先级任务抢占优先级最低、进度最小的运行中任务；保底档不跌破。
- 被抢占任务保存 `progress` 回队，等待时长仍从原始提交时刻计，再次出队携带进度续跑。
- `stats()` 输出配额使用、抢占记录（含保存的进度）与等待统计；`dump_log(path)` 事件留档 JSONL。
