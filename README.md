# tablelineage2

表级血缘，按任务指纹增量维护，纯标准库。

- `record(job)`：只增改该任务贡献的边，已有边去重不重复；同任务同内容幂等；重录时移除其不再声明的旧边（只保留最新贡献）；成环边截断并返回具体环路路径。
- `remove(job)`：按任务指纹只移除该任务贡献的边，指纹不匹配不动别人的边，并清理删除后的孤立节点。
- 边携带任务指纹和更新时间（`job["time"]`，缺省取当前时间）；任务改名不产生重复边，只换贡献者；增量结果与全量重放一致。
- `query(table=, since=, until=)`：按表（源或目标）和更新时间区间过滤。
