# crawlwarm

现状：冷启动直接开满并发。

问题：站点被瞬间打挂，慢站一直失败，抖动后不回退。

目标：阶梯预热，成功率反馈，回退冷却和重启恢复。

```bash
python3 demo.py
python3 -m unittest discover -s tests
```

阶段口径：档位 1→2→4→8。`warmup(site, window)` 传入一个观察窗口
（`(成功数, 失败数)` 或 bool 序列，样本 ≥4 才评估）；窗口成功率 ≥0.9 升一档，
每窗口最多升一档。`warmup(site)` 无窗口视为无反馈，直接到顶档（兼容旧调用）。

回退口径：窗口成功率 <0.5 或末尾连续失败 ≥3，回退一档并冷却 30 秒，
冷却内不升档。回退记录保留上一档快照（阶段、并发、成功率）。
`dump_state()`/`load_state()` 序列化状态，重启后从当前档继续。
