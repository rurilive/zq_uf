# vulnticket

安全方向的扫描速率调度小工具，按目标反馈自适应调整速率。

- 每个目标独立记一档速率，同一网段互不影响；中断后从上次位置继续扫描。
- 响应变慢（latency_ms 超阈值）、错误率上升（error_rate 超阈值）或出现限流提示（throttle）时降速，反馈恢复后逐步提回默认速率。
- 限流提示保留原文，便于区分目标侧限流和网络问题；连续限流 3 次的目标暂停本轮。
- 降速后给出预计恢复时间（recover_eta，秒）；同一目标调整次数上限 20 次。
- scan(target) 返回当前速率、调整次数、限流提示、续扫位置和降速原因；report() 按目标查看，并给出每次调整的前后取值和触发原因。

运行测试：`python3 -m unittest discover -s tests`
