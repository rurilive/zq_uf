# encodepage

纯 Python 标准库的网页编码识别。入口保持 `decode(body, headers)`，
通过多级回退识别老站点、声明冲突和编码混用的页面。

## 回退顺序

1. **响应头**：解析 `Content-Type` 中的 `charset`，能严格解码（替换字符为 0）即采用，置信度 0.99。
2. **页面 meta**：头缺失或失败时，扫描前 4096 字节，识别
   `<meta charset=...>`、`http-equiv` 写法和 `<?xml encoding=...?>`，
   严格解码成功即采用，置信度 0.95。
3. **字节分布打分**：声明缺失时，对候选编码 `utf-8`、`gbk`、`big5`
   分别以 `errors="replace"` 解码，按解码成功率 `1 - 替换字符/字符数`
   为主、合法多字节序列的字节分布加分（最多 0.01，仅在并列时生效）选编码。

## 冲突与阈值

- **声明与实际冲突**：声明编码严格解码失败时，与候选编码比解码成功率，
  以成功率高者为准，并在 `warnings` 记录冲突告警（基准置信度降到 0.8）。
- **替换字符阈值**：`REPLACEMENT_THRESHOLD = 0.05`（5%）。采用编码的替换字符
  比例超过阈值时，尝试相邻编码（utf-8 / gbk / big5 互为相邻），有更优结果则切换，
  否则保留原编码，两种情况都会告警，基准置信度降到 0.7。
- **全失败兜底**：`HARD_FAILURE_RATIO = 0.5`。所有候选编码成功率均低于 50% 时，
  改用 `iso8859-1` 单字节解码保证不抛异常，置信度 0.1 并记录兜底告警。
- **置信度**：`基准置信度 × (1 - 替换字符比例)`，保留 4 位小数；空 body 直接返回
  空文本、`utf-8`、置信度 1.0。无法识别的声明编码会被忽略并告警。

## 返回值

返回 `DecodedText`（`str` 子类，可直接做字符串比较和拼接），附带：

- `encoding`：最终采用的编码规范名
- `confidence`：0~1 的置信度
- `warnings`：识别过程中的告警字符串列表（无告警为空列表）

## 运行

```bash
python3 demo.py
python3 -m unittest discover -s tests
```
