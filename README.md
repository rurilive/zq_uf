# capticket

现状：所有账号共用一条队列，按到达顺序处理。

问题：高优任务排队，超时不回收，回写后重复暂停。

目标：按优先级分派，账号互斥，超时回收，回写确认一次。

```bash
python3 demo.py
python3 -m unittest discover -s tests
```

实现要点：
- 同一账号同时只有一张活动工单，其余按优先级排队，高优先派；
- 活动工单超时未回写：释放账号、记录超时、账号在该站点进入冷却；
- 冷却按账号+站点区分，到期自动恢复接单，值班同学可手动调整；
- 回写需与工单期望内容匹配，确认只生效一次，重复回写不再触发；
- 超时工单可转派其他账号重新排队；
- 排队位置、账号占用、超时与转派记录均可按账号查看；
- 全部操作事件可导出（export/export_json），并可用 replay 回放重建。
