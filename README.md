# selectorwatch

现状：按站点统计非空字段总数，不区分具体字段，也没有基线。

问题：选择器失效要等入库空值才暴露，告警只有总数定位不到字段。

目标：按站点和字段的命中率与结构基线巡检，低于阈值或突变才告警。

```bash
python3 demo.py
python3 -m unittest discover -s tests
```

基线窗口：每个（站点, 字段）保留最近 20 页样本（`BASELINE_WINDOW`），
首次巡检只学习不告警；命中率基线为窗口内非空页比例，结构基线为窗口内
最常见的（长度档, 数字/字母形态）签名，窗口随每次巡检滑动更新。

告警口径：命中率低于基线的 50%（`HIT_RATE_FLOOR`）或结构签名突变即告警，
同一字段连续 2 页异常升级为 `escalated`（`ESCALATE_AFTER`）；告警后静默
2 轮（`SILENCE_CHECKS`），期间重复告警合并进同一条并累计 `repeats`；
每条告警携带站点、字段、选择器、命中率、基线值和样本页下标。
