# softray

纯标准库软件光栅化器：顶点变换、三角形光栅化、深度测试、简单片段着色器与纹理模型。

```bash
python3 demo.py
python3 -m unittest discover -s tests
```

## 分块与 early-z 口径

- 屏幕按 `tile_size`（默认 32×32，可配）切分为互不相交的块；边界块裁剪到帧缓冲内，跨块三角形按包围盒送入每个相交块，块内独立光栅化，无越界、无缝隙。
- 不透明 pass：块填满后惰性维护块内最大深度 `dmax`；三角形先对块矩形做 Sutherland–Hodgman 裁剪取块内最小 z，`z_min >= dmax` 时整块粗剔除；否则逐像素先做 early-z 深度测试，通过才执行片段着色器并写颜色/深度。
- 透明 pass（`alpha < 255`）：按平均 z 从后往前排序，`src*alpha + dst*(255-alpha)` 整数混合；不参与粗剔除与 early-z，也不写深度，保证前面的不透明表面不会误剔透明片段。
- 纹理路径可开块内 LRU 小缓存（按整数纹素坐标，命中即等价采样），只影响计数与耗时，不改变任何像素颜色。
- 块由 `workers`（默认 CPU 核数）个线程并行处理；块索引区间互不相交，三角形与纹理只读，块内状态线程私有，任意线程数输出逐位一致。
- `Renderer.render_legacy()` 保留原全屏逐像素参考路径，供 demo 与测试做像素/深度逐位比对。
