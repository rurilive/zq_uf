# softray

现状：全屏逐像素执行片段着色器，支持深度测试和简单三角形。

问题：模型一多帧时间顶不住，透明物体和重叠三角形顺序依赖重。

目标：按屏幕分块，粗粒度深度预判、early-z、采样缓存和并行写缓冲。

```bash
python3 demo.py
python3 -m unittest discover -s tests
```

## 分块与 early-z

- 屏幕划分为 `tile_size`（默认 32）像素的块，边界块自动裁剪不越界；跨块三角形按包围盒分发到每个块并在块内裁剪。
- 每个块维护块内深度最大值做粗粒度预判（Hi-Z）：三角形最近深度仍远于块内最远深度时整块跳过。
- 块内逐像素 early-z：只有通过深度测试的像素才执行片段着色器；块内小缓存按精确 `(u, v)` 缓存采样结果，不改变最终颜色。
- 透明三角形（`alpha < 1`）在不透明 pass 之后按质心深度从后往前混合，不写深度，因此不会被 early-z 误剔。
- 颜色/深度缓冲按块并行写入（`num_threads`，默认 CPU 核数），块间区域互不相交，无数据竞争；`render_baseline()` 保留旧逐像素路径用于对照。
