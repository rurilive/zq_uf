# wafregress
安全方向的小工具，用来在日志写入前处理敏感字段。

## 设计
字段级脱敏，替代旧的全量正则替换：敏感字段按服务登记处理方式，业务字段登记后原样保留，
未登记字段在写入路径上直接拒绝（`UnregisteredFieldError`，异常里给出字段名）。

- 处理方式：`full`（整段 `***`）、`partial`（遮中间保留头尾，如 `138****1111`）、`plain`（登记但不处理）
- 规则按 `service` 分开配置，同名字段在不同服务可用不同方式；`configure` 追加版本号，变更只对新日志生效
- `rollback` 按服务回滚，以追加新版本实现，历史可审计（`versions` 查询）
- `mask` 返回脱敏字段、处理方式、未登记字段和稳定关联标识 `trace_id`（基于原始 record，规则变更前后不变）
- `report` 按服务汇总：处理条数、遮蔽字段数、未登记字段数及按字段名明细、关联标识数

## 运行
```
python3 demo.py                 # 端到端演示
python3 -m unittest discover -s tests   # 单元测试（21 个）
```
