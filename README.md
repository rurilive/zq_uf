# compact

现状：把目录下所有文件按名字合并成一个。

问题：小文件仍很多，合并期间新写入会漏，失败留半个结果。

目标：按大小策略、参与清单、原子改名和校验回滚。

```bash
python3 demo.py
python3 -m unittest discover -s tests
```

策略参数（policy 字典，缺省用默认值）：
- max_file_size：单文件小于该字节数才参与合并，默认 1MB。
- max_batch_size：单批总大小上限，超出自动分批，默认 8MB。
- min_age_seconds：只合并修改时间早于该秒数的文件，跳过正在写入的新文件，默认 0。

合并前快照参与文件清单，完成后按清单删除源文件，期间新增文件不参与本轮。
先写临时文件并校验行数与 SHA-256，一致才原子改名；校验失败或写入异常会
删除临时文件、保留全部源文件（回滚）。单批返回路径字符串，多批返回路径列表。
