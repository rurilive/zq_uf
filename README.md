# ssoflow

安全方向的敏感列发现小工具，纯标准库。

按内容和命名一起判断：采样内容匹配敏感模式（证件号、联系方式、地址、账号），
列名和注释作为辅助依据。命中给出行列位置和样例，同一类数据在不同表里归到同一等级。

- `discover(table)` / `report()`：扫描入口和按库汇总（敏感列数、涉及表数、等级分布）
- `hits(table)` / `samples(table, column)`：按表看命中、按列看样例
- `adjust(...)` + `rescan()`：人工调整认定结果并记住，只重扫受影响的表
- `export(database)`：分级结果按库导出成清单
