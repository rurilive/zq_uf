# dirprobe

安全方向的子域枚举收敛小工具，把一轮候选整理成入口清单。

候选按解析结果收敛：指向同一地址的名字合并成一条入口并保留全部名字；
通配解析（`status: "wildcard"`）产生的名字单独标出并保留原始解析记录，
确认误判后可用 `restore(domain, name)` 单独恢复；解析失败和超时分开计数，
重新枚举时自动跳过已确认无效的名字。

`enumerate(domain)` 返回有效入口、别名、通配命中和无效数量；
`report(domain)` 按域名上报真实覆盖（有效入口数而非候选条数）；
结果按域名和轮次分开存放，`diff(domain)` 只看最近一轮的新增部分。
